# 에이전트 반복 실수 기록 (agent-mistakes)

AI가 **반복적으로** 저지른 실수, 그 원인, 재발 방지책을 한 곳에 모은다.
`docs/logs/`가 기능별 시도 이력이라면, 이 문서는 **기능을 가로지르는(cross-cutting) 실수 학습 루프**다.

> **Plan 단계에서 이 문서를 먼저 읽는다.** 새 작업의 계획을 세우기 전에 과거의 반복 실수를 확인해 같은 함정을 피한다.

## 기록 조건 (남용 금지)

- **재현 가능한 실제 실패**만 기록한다. 추측·일회성 환경 오류·아직 재현 못 한 우려는 여기 넣지 않는다(그건 해당 기능의 `docs/logs/`에만).
- 같은 원인이 **2회 이상** 나타났거나, 한 번이라도 **비용이 큰** 실패일 때 승격한다.
- 각 항목에는 **실수 / 원인 / 재발 방지**를 모두 적는다.

## 기록 표

| 날짜 | 실수 | 원인 | 재발 방지 |
| --- | --- | --- | --- |
| (예) 2026-07-13 | 승인 전에 코드를 먼저 생성함 | 휴먼 게이트를 단계로 착각 | Plan 결과는 항상 "승인 요청"으로 끝내고, 승인 메시지 없이는 Write/Edit 금지 |

## 워크플로우 연결

- **Plan**: planner가 이 문서를 읽고, 관련 실수가 있으면 계획에 회피책을 반영한다.
- **Evaluate 후**: 반복·고비용 실패가 확인되면 evaluator(또는 사용자)가 이 표에 한 줄 추가한다.
- 개선 지표: "같은 원인으로 재발한 항목 수"가 줄어드는지가 하네스가 학습하고 있다는 신호다.
